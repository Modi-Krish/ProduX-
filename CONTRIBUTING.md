# Contributing to ProduX

First off, thank you for considering contributing to ProduX! It's people like you that make open-source such a great community.

## 🚀 How Can I Contribute?

### Reporting Bugs
If you find a bug, please use the provided Issue Template. Include as much detail as possible: steps to reproduce, expected behavior, and your environment.

### Suggesting Enhancements
Have an idea for a new feature? Open an issue! We love discussing new ways to improve productivity and social features.

### Pull Requests
1. Fork the repo and create your branch from `master`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code follows our linting rules.
6. Submit your PR using the template.

## 💻 Development Setup

1. Clone your fork.
2. Run `npm install` in the root and `client/` directories.
3. Copy `.env.example` to `.env` and fill in your MongoDB credentials.
4. Start development server: `npm run dev`

## ⚖️ Code of Conduct
Please be respectful and kind to others. We enforce a professional, inclusive environment. Harassment of any kind will not be tolerated.
